
PROJECT NAME: AssetTrackr

========================================
1. REVISED ATOMIC FEATURE LIST
========================================

--- EMPLOYEE FEATURES ---

Feature: Create a new employee
API Endpoint: POST /api/employees
Database Action: INSERT a new row into employees table (name, email, department)

Feature: View all employees
API Endpoint: GET /api/employees
Database Action: SELECT all rows from employees table

Feature: View single employee details
API Endpoint: GET /api/employees/{id}
Database Action: SELECT row from employees WHERE id = ?

Feature: Update employee details
API Endpoint: PUT /api/employees/{id}
Database Action: UPDATE employees SET name, email, department WHERE id = ?

Feature: Delete an employee
API Endpoint: DELETE /api/employees/{id}
Database Action: DELETE FROM employees WHERE id = ?


--- ASSET FEATURES ---

Feature: Add a new asset
API Endpoint: POST /api/assets
Database Action: INSERT into assets table (asset_name, asset_type, serial_number, status)

Feature: View all assets
API Endpoint: GET /api/assets
Database Action: SELECT all rows from assets table

Feature: View single asset
API Endpoint: GET /api/assets/{id}
Database Action: SELECT row FROM assets WHERE id = ?

Feature: Update asset details
API Endpoint: PUT /api/assets/{id}
Database Action: UPDATE assets SET asset_name, asset_type, serial_number WHERE id = ?

Feature: Delete an asset
API Endpoint: DELETE /api/assets/{id}
Database Action: DELETE FROM assets WHERE id = ?


--- ASSET ASSIGNMENT FEATURES ---

Feature: Assign asset to employee
API Endpoint: POST /api/assignments
Database Action:
- INSERT into asset_assignments (asset_id, employee_id, assigned_date, status)
- UPDATE assets SET status = 'Assigned' WHERE id = asset_id

Feature: View all assignments
API Endpoint: GET /api/assignments
Database Action: SELECT all rows from asset_assignments

Feature: View assignments of a specific employee
API Endpoint: GET /api/employees/{id}/assignments
Database Action: SELECT * FROM asset_assignments WHERE employee_id = ?

Feature: Return an asset
API Endpoint: PUT /api/assignments/{id}/return
Database Action:
- UPDATE asset_assignments SET return_date = CURRENT_DATE, status = 'Returned'
- UPDATE assets SET status = 'Available' WHERE id = asset_id

Feature: View asset history
API Endpoint: GET /api/assets/{id}/history
Database Action: SELECT * FROM asset_assignments WHERE asset_id = ?


--- HR ADMIN FEATURES ---

Feature: Add HR admin
API Endpoint: POST /api/hr
Database Action: INSERT into hr_admins (name, email, role)

Feature: View all HR admins
API Endpoint: GET /api/hr
Database Action: SELECT all rows from hr_admins

Feature: Delete HR admin
API Endpoint: DELETE /api/hr/{id}
Database Action: DELETE FROM hr_admins WHERE id = ?
